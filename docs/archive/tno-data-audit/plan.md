# TNO 数据总审计计划

## 目标
对 data/scenarios/tno_1962 及其构建/运行时支撑链路做一次系统化总审计，重点查找：
- 地块消失
- 海洋或湖泊重叠
- fallback 地块计算错误
- 逻辑漏洞、代码冗余、架构错漏
- 现有验证盲区

## 执行口径
1. 先查根因与证据，再给结论。
2. 并行三条线：代码/架构 review、底层数据静态核查、现有验证覆盖面审计。
3. 主线程独占验证命令，子代理只做静态分析。
4. 最终按严重度输出：已证实问题、可能风险、验证盲区。
