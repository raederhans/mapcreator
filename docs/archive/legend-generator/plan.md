# 图例生成器计划

## 目标
在项目图例面板中新增图例生成模式，支持随机、按实控面积、按阵营面积、大洲聚焦，并把生成出的图例标签与配置纳入项目状态。

## 验收
- 图例面板出现生成模式、应用按钮和大洲/排序配置。
- 生成后地图颜色刷新，图例 label 自动填入势力名且可手动修改。
- 支持按当前实控面积排序、含附庸/辖区聚合排序、大洲聚焦排序、主要国家加权随机。
- 图例 label 与配置进入项目保存/加载 payload。
- 针对 LegendManager 或控制器新增/扩展测试，pages-dist 同步通过。
