## Source Direction

General rule:

1. Use official/regulator geometry when open and reproducible.
2. Use official/common registries for airports, ports, energy, and mineral points.
3. Use Geofabrik/OpenStreetMap geometry for road and rail only when official bulk geometry is gated, unavailable, or fragmented.

  - Energy: use EIA-860 for U.S. plants; WRI/GEM can be a global fallback.
  - Minerals: use USGS USMIN/MRDS-style sources for U.S. mineral point packs.
- Germany:
  - Keep BKG DLM250 as the complete reference sample.

OSM/Geofabrik filters:

- Road: keep `highway=motorway|trunk|primary|secondary|tertiary|unclassified|residential|living_street|service`. Keep `track` out of the first pass unless a facility/logistics sublayer explicitly needs it.
- Road exclusions: `path`, `footway`, `cycleway`, `proposed`, `construction`.
- Rail: keep `railway=rail|light_rail|subway|tram|monorail|narrow_gauge|funicular`.
- Rail exclusions: `abandoned`, `disused`, `razed`, `proposed`.
- Use explicit stations, yards, ports, airports, and facility point datasets. Do not infer point assets from line endpoints.
- Keep whole ways inside the chosen Geofabrik extract and clip only through the established builder pipeline.

## DataTab Direction

DataTab is technically useful only if it is linked with map selection and filters. A static table would duplicate the inspector. The useful version is:

- Right deck hosts the Data tab.
- Data tab consumes the same preview snapshot as the map.
- Table row click selects the corresponding map feature.
- Map click updates the selected table row.
- Table rows expose source fields, normalized fields, and delta/edit state.

Minimum data shape:

```js
{
  familyId,
  packId,
  mode,
  variant,
  selectedId,
  runtimeStats,
  tableRows: [
    { key, label, kind, value, sourceVersion, deltaState, errorCode }
  ]
}
```
