# Renderer Transformed Frame Compositor Owner P2.2b

## Objective

P2.2b extracts transformed-frame buffer composition and cached-frame selection from `js/core/map_renderer.js` while preserving visible-frame behavior. The canonical owner is `js/core/map_renderer/transformed_frame_compositor_owner.js`.

## Ownership boundary

The owner contains `composeTransformedFrameToBuffer()` and `drawTransformedFrameFromCaches()`. It receives bounded constants, getters, helpers, and effects. Runtime state writes remain composition-root effects in `js/core/map_renderer.js`.

The stable wrappers in `js/core/map_renderer.js` continue to expose the existing internal function names. `draw_canvas_orchestration_owner.js` continues to call the `drawTransformedFrameFromCaches` wrapper.

## Preserved behavior

- Cached-pass preflight completes before the visible canvas reset.
- HGO transformed frames preserve failure metrics, timings, and counters.
- Interaction-composite rejection writes occur before invalidation.
- Interacting frames defer synchronous composite builds.
- Dirty settling frames preserve continuity, timing, and exact-political write semantics.
- Border snapshot fallback preserves DPR, translation, scale, and labels-last order.
- Buffer blit occurs after the render-target scope exits.

## Protected adjacent surfaces

- `drawTransformedPass()` and `composeRenderPassesToTarget()` remain owned by `js/core/renderer/cached_pass_compositor_owner.js`.
- Interaction composite build/draw, border drawing, pass drawing, `renderPassToCache()`, exact scheduling, scenario refresh, hit-canvas work, strategic overlays, and click effects remain in their existing owners or the composition root.
- Public facade, RendererRuntimeContext, and state-write allowlist remain unchanged.
- P53 historical preflight remains retained as the architecture inventory.

## Verification contract

- Node behavior: `npm run test:node:transformed-frame-compositor-owner`
- Combined boundary: `npm run test:python:map-renderer-frame-compositor-boundary`
- P53 inventory: `npm run test:node:renderer-draw-canvas-orchestration-inventory`
- Default suite: `npm run test:node:transformed-frame-compositor-owner-suite`
- Final deterministic gate: `npm run verify:core`
- Browser/perf acceptance remains a required P2 closeout gate.

## Line-budget outcome

The P2.2b source move lowers `js/core/map_renderer.js` from 23,375 lines to 23,278 lines. The new owner is bounded to 420 lines. P2.1 through P2.2b reduce the renderer composition root by more than the 150-line P2 target without moving pass drawing functions.
