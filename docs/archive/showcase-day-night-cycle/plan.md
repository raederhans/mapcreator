# Showcase Day-Night Cycle Plan

## Goal

Replace the unclear Europe showcase `scenario` tab with a `day-night` layer that visibly demonstrates a day-night cycle over the generated Europe 1936 map.

## Acceptance

- The visible showcase tab says `Day-Night` in English and `昼夜` in Chinese.
- The old `scenario` tab and copy are removed from the landing showcase.
- The generated SVG contains a `day-night` layer with an animated night/terminator treatment.
- The metadata layer list is `political`, `rail`, `cities`, `day-night`.
- `landing` and `dist` remain synchronized through `npm run verify:pages-dist`.

## Scope

- Landing source: `landing/index.html`, `landing/app.js`
- Showcase generator and generated assets: `tools/build_landing_europe_1936_showcase.py`, `landing/assets/europe-1936-showcase.svg`, metadata JSON
- Delivery surface: `dist/*` generated by the pages-dist build
- Tests: `tests/test_pages_dist_startup_shell.py`

## Constraints

- Keep the implementation inside the existing showcase layer system.
- Do not introduce a new dependency.
- Keep the SVG XML-valid because it is embedded through `<object type="image/svg+xml">`.
- The metadata JSON remains checked in because app.js uses it to validate available layers.
