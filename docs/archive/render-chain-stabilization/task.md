# Render Chain Stabilization Task

## Scope

Execute the agreed "stabilize first, split second, measure before optimizing" plan for the scenario rendering chain.

## First Batch

- Color refresh must invalidate only the passes that consume the changed color source.
- Water region selection highlights must update immediately after selection-only actions.
- Startup visual readiness must not report success before political visual data is actually available.
- Pages dist manifest generation must stay stable across Windows and LF-oriented CI checkouts.

## Later Batches

- Extract narrowly defined renderer responsibilities after correctness tests are in place.
- Add metrics before adopting spatial-index or worker/offscreen rendering dependencies.
- Evaluate `flatbush` and OffscreenCanvas only when measured bottlenecks justify the added contract.
