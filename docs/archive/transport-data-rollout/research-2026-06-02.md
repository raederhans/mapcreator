## Source Direction

Preferred source chain:

1. Official national or regulator geometry when it is open and reproducible.
2. Official/common registry points for airports, ports, power plants, and mineral sites.
3. Geofabrik/OpenStreetMap geometry for road and rail only when official geometry is gated, unavailable, or too fragmented.

Country notes:

- USA: keep Census TIGER primary roads for road. Add rail through BTS NTAD. Airport stays FAA-backed. Facility families can use EIA/WRI/GEM for energy and USGS for mineral resources.
- Germany: keep BKG DLM250 as the complete reference sample.
- UK: keep OS Open Roads for Great Britain. Rail needs a reproducible open source route before build work; facility families should start from global point datasets plus UK-specific filtering.
- France: add metropolitan France road through IGN BD TOPO or another reproducible official/open road layer. Rail is already SNCF-backed. Facility families can use global point datasets, filtered to metropolitan France.
- China, India, Russia: first add road and rail through Geofabrik/OpenStreetMap geometry with strict filters and country-mainland scope notes. Add facility families from global point datasets before trying large polygon layers.

Scope rules:

- UK and France preview scope should use the national mainland/metropolitan scope that matches the data. Overseas territories stay outside first-wave packs unless the data source explicitly covers and the pack contract says so.
- Russia may include Kaliningrad because it is part of the main Russian state transport scope and should remain visible in the country carrier.
- USA scope needs an explicit decision per pack: contiguous USA only for simple mainland line previews, or CONUS plus Alaska/Hawaii for national packs that have reproducible national geometry. Current `usa_road` includes national coverage and its bbox reflects Alaska/Hawaii.

## UI And Workbench Findings

Likely stutter path:

- `transport_workbench_carrier.js` calls `applyCamera()` on wheel, pointer drag, and zoom buttons.
- Each camera change calls the view listener.
- `transport_workbench_preview_lifecycle_owner.js` schedules a RAF view sync and refreshes preview.
- Point-family preview rebuilds visible entries, marker nodes, label nodes, and aggregation state.
- Filter changes also trigger lens and inspector rendering before preview refresh, then inspector rendering again after preview refresh.

First UI fix shape:

1. Keep carrier transform updates immediate.
2. Coalesce preview refresh and inspector refresh behind one RAF per frame.
3. Avoid point preview full DOM rebuild when only camera transform changed and the feature/filter signature is unchanged.
4. Add a narrow behavior test around view sync coalescing and filter-triggered inspector refresh count.

## External Evidence

- [BTS NTAD](https://www.bts.gov/ntad): national transportation facility/network geodatabases and attributes.
- [Census TIGER Primary Roads](https://catalog.data.gov/dataset/tiger-line-shapefile-2023-nation-u-s-primary-roads): supported Census road geometry product.
- [FAA Airport Data](https://www.faa.gov/air_traffic/flight_info/aeronav/aero_data/Airport_Data/): official FAA airport data portal for U.S. airports.
- [UNECE UN/LOCODE](https://unece.org/trade/uncefact/unlocode): official trade and transport location code list, useful for ports.
- [OS Open Roads](https://www.ordnancesurvey.co.uk/products/os-open-roads): official Great Britain road network product.
- [IGN BD TOPO](https://geoservices.ign.fr/bdtopo): official French topographic data source for road geometry candidates.
- [SNCF Open Data](https://data.sncf.com/): official France rail open data source.
- [BKG DLM250](https://www.bkg.bund.de/SharedDocs/Produktinformationen/BKG/DE/P-2025/250520_DLM250.html): German 1:250,000 landscape model used as the complete sample source.
- [Geofabrik](https://www.geofabrik.de/en/data/index.html): OSM country extracts for road/rail geometry where official bulk geometry is not practical.
- [WRI Global Power Plant Database](https://developers.google.com/earth-engine/datasets/catalog/WRI_GPPD_power_plants) and [GEM Global Integrated Power Tracker](https://globalenergymonitor.org/projects/global-integrated-power-tracker/): global energy facility candidates.
- [USGS mineral resources data](https://www.usgs.gov/programs/mineral-resources-program/mineral-resources-data): U.S. and global mineral resource candidates.
- [D3 projection `fitExtent`](https://d3js.org/d3-geo/projection): still the correct viewport-fitting mechanism for carrier JSON.
- [MDN `requestAnimationFrame`](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame) and [web.dev long-task guidance](https://web.dev/articles/optimize-long-tasks): supports coalescing UI work to paint frames and splitting heavy main-thread work.
