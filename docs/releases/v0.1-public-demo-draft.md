# v0.1 Public Demo Draft

## Demo URL

- https://raederhans.github.io/scenario-forge/
- Guide path: https://raederhans.github.io/scenario-forge/app/?view=guide

## Public Baselines

- Blank Map
- Modern World
- HOI4 1936
- HOI4 1939
- TNO 1962

TNO 1962 is the default public guided scenario path.

## HGO Local Preview Policy

HGO 1936 remains a developer/local preview. It is separate from the five public baselines and is used for HOI4-style country identity, palette, flag, and raster-render validation.

## Pages Size Status

The Pages distribution is within the 1 GiB hard cap after Phase 2A payload slimming, at about 927.5 MiB.

## Public Release Smoke

The deploy workflow runs the public release smoke after `actions/deploy-pages`, using `steps.deployment.outputs.page_url`.

The release smoke covers:

- Landing root loads.
- `/app/?view=guide` loads and opens the guide path.
- TNO 1962 startup reaches the interactive public scenario path.
- HGO remains hidden or unavailable on Pages.
- Export workbench opens.

## Known Local-Only Systems

- HGO 1936 runtime preview.
- Cloud Saves and community flows through the local backend preview.
- Local backend state under `.runtime/backend/`.
- Large local data preparation and developer validation flows.

## Main Data and Source Families

- Natural Earth for base geography, countries, coastlines, and small-scale reference layers.
- geoBoundaries for administrative boundary reference data.
- GeoNames for place names and settlement reference data.
- NOAA ETOPO 2022 for relief, bathymetry, and terrain context.
- NASA Black Marble for night lights and city-light texture context.
- OpenStreetMap and Geofabrik for roads, rail, facilities, and transport/context extracts.
- Japanese MLIT road data (N06) for Japan road hardening and transport preview reference data.

Detailed records live in `data/source_ledger.json`, `.provenance.json` files under `data/`, source recipes under `data/transport_layers/`, and generated asset source records.

## Known Limitations

- The public demo exposes five public baselines; HGO 1936 remains a developer/local preview.
- Roads and rail are the strongest public transport paths. Airports and ports provide overview context. Mineral resources, energy, industry, and logistics remain preview/workbench families.
- Cloud Saves, public community posts, downloads, comments, reports, and admin moderation require the local backend preview.
- Some large data preparation and validation flows require a local Windows/Python setup.
