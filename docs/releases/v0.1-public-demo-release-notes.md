# GitHub Release Notes Draft: v0.1-public-demo

## What This Release Is

Scenario Forge v0.1 public demo packages the first public, editable sample flow for the browser-hosted map workbench. It focuses on opening a real sample, understanding it through the Guide, switching between public starter projects, and proving an export path.

## Try The Demo

- Demo: https://raederhans.github.io/scenario-forge/
- Guide: https://raederhans.github.io/scenario-forge/app/?view=guide
- TNO sample: https://raederhans.github.io/scenario-forge/app/?sample=tno-1962-atlantropa-briefing&view=guide

## Public Samples

- Blank Map starter
- Modern World Japan corridor
- HOI4 1936 Europe briefing
- HOI4 1939 Europe switch
- TNO 1962 Atlantropa briefing

HGO 1936 remains a developer/local preview and is excluded from the public sample set.

## Export Proof Path

Each public sample includes recommended export metadata. The Guide shows the recommendation label, and Export Workbench shows the loaded sample context plus format, scale, and target summary.

## Local-Only Systems

- HGO 1936 runtime preview.
- Cloud Saves and community flows through the local backend preview.
- Local backend state under `.runtime/backend/`.
- Large local data preparation and developer validation flows.

## Verification

- Canonical release facts live in `docs/releases/v0.1-public-demo.md`.
- Local validation passed across Pages dist generation, dist drift, i18n audit, sample Guide E2E, local `/dist/` release gate, import graph, and diff checks.
- Deployed release smoke evidence will be recorded in the P7 closeout after the Pages deploy.

## Known Limitations

- Roads and rail are the strongest public transport paths.
- Airports and ports provide overview context.
- Mineral resources, energy, industry, and logistics remain preview/workbench families.
- Cloud Saves, public community posts, downloads, comments, reports, and admin moderation require the local backend preview.
- Some large data preparation and validation flows require a local Windows/Python setup.

Release type recommendation: publish as a pre-release for v0.1.
