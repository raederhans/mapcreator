## 目标

把生成后的地图图例从 SVG 绘制层拆成独立浮动控件，支持拖动位置、收起和关闭。

## 验收

- 图例使用独立 HTML 控件渲染。
- 用户可以拖动图例、收起图例、关闭图例。
- 重新生成图例会显示控件。
- 图例继续使用当前地图显示颜色和已生成标签。
- 源码与 `dist/app` 交付面保持一致。
